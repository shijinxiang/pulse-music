# PULSE 音乐网站

参考用户提供的 StyleKit 元素库，音乐卡片采用虹彩边框，封面播放按钮采用珍珠银，主播放器采用星芒材质，PULSE 字标采用小卡片标题的连续镭射箔文字。八个音块分别采用彩虹膜、拉丝、星芒、碎钻、点阵、碎冰、光柱、波纹。

[打开音乐网站](https://shijinxiang.github.io/pulse-music/)

- 播放四首原创合成电子音乐，支持切歌、进度控制、音量调节、随机和循环。
- 按风格筛选、搜索和收藏曲目，也能导入本地音频。选中的风格标签展开，邻近标签平滑让位，筛选状态即时更新。
- 使用 A、S、D、F、G、H、J、K 弹奏 C4、D4、E4、F4、G4、A4、B4、C5 八个音，体验音符粒子和沉浸声场。八种音块材质共用一个 WebGL2 渲染器，随指针光源改变反射，提供 CSS 兼容样式。
- 银黑金属耳机与紧凑的白灰尘埃轨道采用早期原始素材，支持鼠标与滚动视差，外缘柔和渐隐。
- 背景参考用户提供的屏幕录制，由 WebGL2 实时生成密集方柱地形、中央暖粉橙色隆起和多中心白紫扩散波。实际音量、瞬态与频谱自适应驱动波纹，波前同时改变方块高度和亮度，静音后自然衰减。本地音频同样适配，提供 Canvas 兼容绘制。
- 主界面和沉浸播放共用方柱地形渲染代码与同一波纹状态，切换时延续扩散中的波纹。
- 页面滚动时，耳机、三个音符与背景以不同深度位移。鼠标靠近耳机旁的音符时，音符向外划开并弹性归位，支持点击与键盘弹奏。
- PULSE 字标沿用最新小卡片参考中的镭射箔文字，用完整字形呈现随指针移动的连续虹彩与银色高光。
- 鼠标移动时留下七彩音符，停止后约 0.3 秒淡出。组件采用统一圆角，大标题使用电光切割字形。
- 鼠标在曲目卡片和音块上移动时，所有箔面以同一指针光源计算虹彩，鼠标指针呈现变色音符。支持键盘操作、触屏与减少动态效果设置。

材质参考来自 [StyleKit Diffraction Foil](https://www.stylekit.top/zh/styles/diffraction-foil)。光栅光谱与 CSS 材质改写自用户提供的参考页面，MIT 许可保存于 `assets/stylekit-LICENSE.txt`。

背景效果的视觉参考为用户提供的屏幕录制。运行时的方柱、波纹、灯光与动画均由代码计算。

页面使用 HTML、CSS 和 JavaScript，字体与图片随仓库提供。字体许可证保留在 `assets/fonts/`。

本地预览可在仓库目录运行以下命令，然后打开浏览器显示的本地地址。

```sh
python -m http.server 8080
```

GitHub Pages 从 `main` 分支的根目录发布。
